## 背景与目标

HONOR 真机（DNN_AN00，Chrome DevTools Protocol 驱动真实按钮）打完 2026/27 全季后报告的四项「不是玩法 bug，但直接咬人」的界面缺陷：

- **问题 2**：标题页存档行的删除按钮 `card grid w-11 place-items-center` 在 flex 行里没有 `shrink-0`，被左边的载入按钮一路压到 **17.7px** 宽 —— 手指按不到，删档等于不可能。
- **问题 3**：弹窗（如「安排本周」）开着时按系统返回键**直接退出应用**。`registerBackButton` 只看路由，不知道屏幕上有弹窗。
- **问题 8**：建号页/设置页的原生 `input[type=range]` 只有约 **16px** 高，主题切换按钮实测 **33px** 宽 —— 都低于 44px 触控底线。
- **问题 9**：删档确认走 `window.confirm`，按钮是英文 **CANCEL / OK**，且不受返回键栈管；原生 App 的标题页与隐私页写着「存档保存在本机浏览器」；两份同名存档在列表里几乎无法分辨；删除按钮的 `aria-label` 在中文里塞了两个多余空格。

真正要修的不仅是这四处，还有**让它们漏检的口径**：`tests/ui/layoutHarness.ts` 只有 `minHeightPx`，布局契约从头到尾**没量过宽度**，所以 17.7px 这种缺陷结构上不可能被测出来。本 CHG 把宽度维度与滑块维度补进契约，同类问题才有自动化闸门。

本次不做：不改引擎与世界生成、不动 `save.schema.ts` 与 `ENGINE_VERSION`、不动 golden、不做问题 13/14 的数值调整。

## 验收条件

- 纯图标按钮与 flex 行里的定宽控件，在类名口径上必须给出 ≥44px 的**最小宽度**（`min-w-11` / `min-w-[44px]`，或 `shrink-0` / `flex-none` 保住标称定宽）。
- `input[type=range]` 必须有 ≥44px 的命中高度（统一走 `.slider` 组件类）。
- 弹窗打开时 `closeTopModal()` 返回 `true` 并调用该弹窗的 `onClose`；`dismissible={false}` 与未打开的弹窗不进栈；栈为空时返回 `false`，返回键行为与改动前完全一致。
- `registerBackButton` 的拦截器在路由判断**之前**执行；不传第二个参数时旧调用方行为不变。
- 删档确认（标题页存档行 + 设置页危险区）渲染 `role="dialog"` 的应用内弹窗，`window.confirm` 零调用，界面里不出现 CANCEL/OK。
- 原生 App 的标题页与隐私页不再出现「本机浏览器」；Web 端保留原话。
- 存档行给出「保存于 月-日 时:分」，两份同名档的文本可分辨。
- 测试数量不下降，`npm run verify -- --fast` 全绿。

## 方案与取舍

- **弹窗协同走 `ui` 内模块级栈，由 `app` 注入 `platform`**：`ui` 不得依赖 `app`（`docs/modules.yaml`），而 `SeasonSummaryModal` 挂在 `app/GameLayout.tsx`；把栈放在 `Modal.tsx` 里、由组合根 `App.tsx` 把 `closeTopModal` 交给 `registerBackButton`，是三条依赖边都合法的唯一走法。
- **不用 popstate 哨兵**：`router.tsx` 是 `createHashRouter`，`pushState` 哨兵会和 `backButton.ts` 的 hash 白名单（`''`/`'`/`/game`）打架；纯内存栈不动 hash，卸载时按回调身份摘除，重放/刷新不留悬空项。
- **`min-w` 走类名而不是布局引擎**：jsdom 不跑布局，`getBoundingClientRect()` 恒为 0，契约只能断言类名口径。真实像素仍由真机 `getBoundingClientRect().width` 复核（已写进「真机验收」第 4 条）。
- **`.slider` 不套 `appearance-none`**：自定义 `::-webkit-slider-thumb` 才能改轨道外观，但那是视觉重写，风险大于收益；这里只把命中盒子撑到 44px，轨道仍交系统绘制。
- **`ConfirmDialog` 是通用件而不是两处各写一份 Modal 脚部**：标题页与设置页的确认框只差标题与 detail 文案，复制会撞重复率口径。
- **时间戳不新增 `SaveSummary.createdAt`**：`updatedAt` 已在 `saveTypes.ts` 与 `repository.ts:38` 落盘并随每次保存刷新，加字段等于第二份真相；`formatSavedAt` 留在 `src/ui/screens/title/saveStamp.ts` 而不是 `src/lib/format.ts` —— `tests/engine/determinism.test.ts` 把 `src/lib` 也罩在「禁止 `new Date(`」里，读墙上钟的展示函数放进去会破确定性守卫。
- **`aiSlice.ts` 的「已加密保存在本机浏览器」不是缺陷**：它按 `storeApiKey` 真实返回的 `persisted` 三态选词，原生分支早已存在，本 CHG 不动它。

## 防回归

- `tests/ui/touchSizeContract.test.tsx` 与 `layoutHarness` 的 `fixedWidthPx` / `minWidthPx` / `squashedTargets` / `iconOnlyTargets` / `rangeInputs` 是新增的**宽度维度**：以后任何页面把定宽控件放进 flex 行而不给 `shrink-0`，或用裸 `input[type=range]`，都会在契约层失败，而不是等真机长按才发现。
- `tests/ui/modalStack.test.tsx` 钉住栈语义四件事：可关闭才进栈、未打开不进栈、卸载即摘除、LIFO 顺序。`tests/platform/backButton.test.ts` 钉住拦截器先于路由判断、且不传时旧行为不变。
- `tests/ui/titleStorageCopy.test.tsx` 用可变的平台探针 mock 同时覆盖标题页与隐私页，`native.value` 在 `afterEach` 复位，避免「文案只在 Web 下绿」。
