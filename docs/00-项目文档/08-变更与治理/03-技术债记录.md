# 技术债记录

## 机器事实源

技术债的机器事实源是：

- `quality/tech-debt-baseline.json`
- `quality/coverage-baseline.json`
- `quality/duplication-baseline.json`
- `npm run quality:report`

基线由 `npm run quality:update` 只降低/删除，不手工抬高。本文件只登记**需要人决策的接受债务**，不复制全部基线条目。
