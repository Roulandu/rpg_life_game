# 项目概述

绿茵人生（rpg-life-game）是一款单机足球生涯模拟游戏：玩家从 17 岁青训起点开始，经历训练、比赛、成长、合同、财务与退役。游戏事实全部由本地确定性引擎计算，不依赖自建后端；唯一可选外部依赖是玩家自行配置的 LLM 接口。

## 技术形态

| 项 | 说明 |
|---|---|
| 前端 | React 19 + TypeScript 7 + Vite 8 + Tailwind CSS 4 |
| 状态 | Zustand |
| 持久化 | Dexie / IndexedDB，导出文件为 JSON |
| 多端 | Web / PWA；Android 通过 Capacitor 壳复用同一套 Web 产物 |
| 测试 | Vitest + Testing Library + V8 coverage |
| 质量 | oxlint、jscpd、模块边界、技术债基线、文档同步、变更记录 |
| LLM | 仅写叙事与受约束提案，不直接改游戏事实 |

## 模块

`app / ui / store / engine / world / llm / db / platform / domain / lib`。依赖方向与允许依赖以 `docs/modules.yaml` 为唯一事实源，说明见 [模块边界与依赖规则](../02-架构设计/02-模块边界与依赖规则.md)。

## 快速开始

```bash
npm ci
npm run dev
npm run verify -- --help
npm run verify -- --fast
npm run verify -- --full
```

常用入口：

- 类型与单测：`npm run typecheck`、`npm test`
- 覆盖率：`npm run test:coverage`
- 文档生成与检查：`npm run docs:build`、`npm run docs:check`
- 修改文件前上下文：`npm run quality:file -- <path>`
- 提交信息检查：`npm run quality:commit-msg -- <message-file>`

## 不可破坏的约束

- `src/engine` / `src/world` 不读墙钟、不用 `Math.random`；随机数只走 `createRng`。
- LLM 输出只写叙事与受约束提案，不得直接改游戏事实。
- 平台能力只走 `src/platform` 端口；核心域保持平台无关。
- 存档结构变化必须升版本、提供迁移、旧档 fixture 与导入/导出往返测试。
- 禁止提交密钥、Token 与真实个人信息。

完整硬规则见仓库根 `AGENTS.md`。
