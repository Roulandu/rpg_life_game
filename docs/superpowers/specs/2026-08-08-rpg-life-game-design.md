# RPG 风格人生模拟器 — 设计文档

- 日期：2026-08-08
- 状态：草案（项目骨架已建立）

## 目标

打造一个 **RPG 风格的人生模拟器**网页游戏。玩家扮演角色，从出生到终老，通过回合制的**事件选择**推进人生，角色属性随选择和年龄不断成长。

## 核心玩法

- **属性养成 + 事件选择**：玩家拥有基础属性（如智力、体力、魅力、财富等），在每个生命阶段/回合面对随机或预设事件，做出选择会改变属性、获得/失去资源，或解锁后续事件。
- **年龄成长**：随回合推进年龄增长，不同年龄阶段（童年、求学、工作、晚年等）开放不同的可选项与事件池。
- **生涯与结局**：人生走向受前期选择影响，最终可能形成多种结局（如事业有成、穷困潦倒、家庭美满等）。

## 技术选型

- **平台**：网页游戏（Web/HTML5），浏览器直接运行。
- **前端**：React 19 + TypeScript。
- **构建**：Vite。
- **代码检查**：oxlint。
- **工程**：npm + git + GitHub（公开仓库，`Roulandu/rpg_life_game`）。

## 架构（规划）

游戏逻辑与 UI 分离，后续可按模块拆分为：

- **角色状态模块**：属性、年龄、资源、生命阶段。纯数据 + 派生逻辑，便于测试。
- **事件模块**：事件定义（前置条件、选项、效果）、事件选择器（含随机权重）。
- **生涯/阶段模块**：按年龄或人生阶段管理可选操作与事件池。
- **存档模块**：状态序列化/反序列化，本地持久化（localStorage）。
- **UI 层**：React 组件 —— 属性面板、事件卡片、日志、结局画面。

## 数据流（规划）

```
用户选择事件选项
  → 事件效果计算（属性/资源变动、触发后续事件）
  → 角色状态更新 + 年龄推进
  → 根据新状态筛选下一阶段可选事件
  → 渲染新事件卡片
```

## 错误处理（规划）

- 事件效果保证在合法状态范围内（属性有上下限、资源不可为负）。
- 存档读取失败时回退到默认新角色，并提示玩家。

## 测试（规划）

- 核心逻辑（角色状态、事件效果、存档）使用单元测试。
- UI 使用组件测试或手工验证。

## 范围说明

本设计聚焦于**可玩的最小循环**：属性面板 + 回合制事件选择 + 年龄成长 + 存档。不包含联网/多人、地图漫游、战斗系统等（后续可扩展）。
